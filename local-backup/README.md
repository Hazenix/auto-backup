## Auto Backup Scripts

- **English**:  
  This folder contains small helper scripts to automatically commit and push local Git repositories to GitHub.  
  Use the sub‑directories to pick scripts for your operating system.

- **中文**：  
  这里放的是自动备份脚本，用于定时将本地 Git 仓库提交并推送到 GitHub。  
  请根据系统选择对应子目录中的脚本。

---

### Structure

- **`for_windows/`**  
  - Windows batch + PowerShell scripts.  
  - See `for_windows/README_for_windows.md` for details.

- **`for_unix/`**  
  - macOS / Linux shell scripts.  
  - See `for_unix/README_for_unix.md` for details.
